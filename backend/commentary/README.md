# 解釈書（commentary）

教父の注解・ユダヤ教の注解・宗教改革の注解・無教会の講義などを、**本として読める形**と
**「この節にはどんな解釈があるか」を引ける形**の両方で持つアプリ。

```
Work（1冊の解釈書・出典と権利）          ← 聖書の「書」にあたる
  └ CommentaryChapter（章・講・巻）       ← 聖書の「章」にあたる
      └ Section（注解1件・抜粋1つ・段落）  ← 聖書の「節」にあたる
PassageLink（区切り か 章 が、聖書のどの箇所を解釈しているか）
```

画面も聖書と同じ作り（/commentary/<本> = 章の選択＋書へのコメント、/commentary/<本>/<章> = 区切り＋章へのコメント、
区切りを押すとパネル）。コメント・Q&A・お気に入りは「解釈書・章番号・区切り番号」で付く
（Comment / Question / Bookmark の commentary_work ＋ chapter_number ＋ verse_number）。

### 何を1章とするか

| 本 | 章 | 区切り |
|---|---|---|
| カルヴァン・ラシ・カテナ・アウレア（聖書の書ごとに1冊へ分けた） | 聖書の章 | その章の注解1件 |
| 教父の抜粋集 | 聖書の書（聖書の順に 1 から） | 抜粋1つ |
| 『神の国』『異端反駁』など | 原著の巻・章（見出しが変わるところ） | 段落 |
| 内村・藤井の講義 | 講（番号＝講の番号。序は 0） | 段落 |

### 番号を変えない約束

コメント等は番号で付くので、seed を作り直して番号や本文が変わると別の段落に付いてしまう。
`import_commentary` は、コメント等が付いている場所の番号・本文が変わる入れ直しを止める（`--force` で押し切れるが使わない）。

PassageLink の `method` は、節との対応をどうやって知ったか。画面ではこれを必ず区別して見せる。

| method | 意味 | 例 |
|---|---|---|
| `structure` | 本の作りそのものが節ごと | カルヴァン注解の「この節の注解」、ラシ、内村『ロマ書の研究』の各講の対象箇所 |
| `citation` | 本文や脚注に「何章何節」と書いてある | 『異端反駁』の編集者の引用印、「マタイ傳第十六章二一節」 |
| `ai` | 節が書かれていない箇所を AI が推定 | （試験中。本番の seed にはまだ入れない。画面では「AI判定」と明記する） |

## 本番への入れ方

```
python manage.py migrate
python manage.py import_commentary            # commentary/seed/*.json.gz を全部入れる（冪等）
python manage.py import_commentary --dry-run  # 検証と件数だけ
python manage.py import_commentary --only calvin-commentaries
```

ネットにはつながない。同じ slug の本は入れ直すので、何度流しても同じ結果になる。
2026-09-23 の時点で 79 冊・区切り 55,430・箇所 70,981（SQLite で約10秒）。

## seed の作り直し（ローカル専用）

`python manage.py collect_commentary {cdb|ccel|rashi|japanese}`。使い方はコマンドの先頭のコメントを参照。

### 教父の抜粋で除いたもの（collectors/cdb.py）

注解データベースには、権利の違うものが混ざっている。次は**入れていない**。

- 出典 URL の無い抜粋。現代の注解叢書からの引用とみられ、著作権が残る可能性がある
- HCF が ChatGPT で新しく訳した本文（オリゲネスの講話の多く、ヒエロニムスの聖書注解の多く、アンブロシウスのルカ注解、ベーダの注解など）
- 訳者が確かめられない本文（大グレゴリウスの福音書講話・エゼキエル書講話、オリゲネスの雅歌注解など）
- トマス・アクィナス自身の注解（20世紀の英訳）

機械翻訳を入れるかどうかは、あとで決める（入れるなら「機械翻訳」と明記する）。

## 気をつけること

- **CCEL の条件**：CCEL は「個人・教育・非営利の利用は可、商用は要許可」。サービスを営利にするときは、CCEL 由来の5冊を別の入手先（Internet Archive など）から取り直す。
- **詩篇の番号**：教父は七十人訳の番号（1つずれる）で詩篇を数えることがある。CCEL と注解データベースは英語聖書の番号にそろえてあるように見えるが、全部は確かめていない。
- **書名の無い引用**：内村・藤井の本では、書名の無い「八章二八節」をその本が講じている書（ロマ書・ヨブ記・黙示録）の箇所として拾っている。ただし書名付きの引用の直後30字以内にあるものは、別の書の可能性があるので拾わない。
- **年**：`year` はおおよそ。確かめられないものは空にしている。
