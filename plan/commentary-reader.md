# 解釈書を聖書と同じ作りで読む・コメントする

解釈書のページを、聖書の書・章のページと同じ作りにする。
書のページ＝章の選択＋書へのコメント、章のページ＝区切りの一覧＋章へのコメント、
区切りを押すとパネル（コメント・Q&A・引用した記事・お気に入り）が開く。

## 決まっていること（2026-09-23 ユーザー選択）

- 聖書の順に節ごとに注解する本（カルヴァン・ラシ・カテナ・アウレア）は、**聖書の書ごとに1冊へ分ける**
  - 例：「カルヴァン ローマ書注解」。章＝聖書の章、区切り＝その章の中の注解1件
- ほかの本は**本の作りに合わせる**
  - 教父の抜粋集：章＝聖書の書（例：クリュソストモス › ローマ書）、区切り＝抜粋1つ
  - 『神の国』『異端反駁』など：章＝原著の巻・章、区切り＝段落
  - 内村・藤井：章＝講、区切り＝段落
- パネルは**聖書と同じ全部**（コメント・Q&A・引用した記事・お気に入り）

## 設計

### 場所の持ち方
コメント・Q&A・お気に入り・記事の引用は、いま「書（CanonicalBook）＋章番号＋節番号」で場所を持つ。
これに `commentary_work`（解釈書）を足し、**「聖書の書」か「解釈書」のどちらか一方**＋章番号＋区切り番号で持つ。
章番号・節番号の列はそのまま使い回す（解釈書では節番号＝区切りの番号）。

### 番号は変えない約束
コメントなどは「解釈書・章番号・区切り番号」で付く。seed を作り直して番号がずれると、
コメントが別の段落に付いてしまう。そこで `import_commentary` は、**コメント等が付いている解釈書の
番号や本文が変わるときは止まる**（`--force` で押し切れるが、使わない前提）。

### 解釈書の章
`CommentaryChapter`（解釈書・章番号・題）を足し、区切り（Section）に章番号と区切り番号を持たせる。
講や巻のように「章そのもの」が聖書の箇所を論じることがあるので、PassageLink は区切りか章のどちらかに付く。

## 手順

1. [x] データの形：章を足し、seed を新しい分け方で作り直す（本の数が増える）。番号を変えない安全装置
2. [x] 場所の一般化：コメント・Q&A・お気に入りを解釈書の場所でも持てるようにする（記事の引用は 5 で）
3. [x] API：解釈書の書（章の一覧）・章（区切りの一覧）、場所ごとのコメント・Q&A・お気に入り
4. [x] 画面：/commentary/<本>（章の選択＋書へのコメント）、/commentary/<本>/<章>（区切り＋章へのコメント＋パネル）
5. [x] 記事から解釈書を引用できるようにする（印は [[@解釈書 章:区切り]]）。プランにも解釈書の章を入れられるようにする
6. [x] お気に入り一覧・Q&A一覧・通知で、解釈書の場所を正しく表示し、そこへ飛べるようにする
7. [ ] 本番：seed の入れ直し（Render シェルで import_commentary）

## 残り・メモ

- 講の番号＝章の番号にした（内村『ロマ書の研究』の序は 0 章）
- 解釈書の一覧（/commentary）は本が約80冊に増えた。カルヴァンは48冊並ぶので、まとめ方は見ながら決める
