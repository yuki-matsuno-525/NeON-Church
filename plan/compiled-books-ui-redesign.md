# 編纂UI 再設計 進捗

既存の編纂機能（`plan/compiled-books-progress.md`）は、機能はあるが操作の骨格が無い。
「集めた断章を、ドラッグで章に並べていく」という編纂の中心動作ができる形に作り直す。

## 決まったこと

- ドラッグの向きは **右の断章ボックス → 左の章**。
- 断章ボックスは **編纂書ごとに1つ**。一般名は「断章ボックス」、そこに個別名を付けられる（例:「拾った断片」）。
- 章から外すのは削除ではなく **「断章ボックスに戻す」**。断章ボックスからは削除できる（そこが最終地点なので）。
- 読む画面から追加したあとに編纂書へ飛ぶリンクは **作らない**（読書が途切れるため）。入った断章ボックスの名前だけ出す。

## 画面の構成

```
/compilations              編纂書の一覧（既存）
/compilations/new          新しい編纂書をつくる（書名・説明・注釈）→ 作成したら下の設定ページへ
/compilations/[id]/edit    ★前のページ＝書の設定・章の追加・章の一覧・断章ボックスの名前・公開範囲
                           章を選ぶと ↓ へ
/compilations/[id]/edit/chapters/[chapterId]
                           ★作業ページ＝左に章／右に断章ボックス。ドラッグで並べる
/compilations/[id]         閲覧ページ（/genesis/2 と同じ見た目にする）
```

### 作業ページの形

```
┌──────────────────────┬─────────────────────┐
│ 第1章 光をわけた日        │   [普通の本文を追加] │
│                       │ ── 断章ボックス「拾った断片」──│
│  1. 創世記 1:3         │  ・エノク書 6:2      │
│  2. （ここへドロップ）    │  ・トマス福音書 3     │
│      ↖───────────────│  ・自分で書いた本文    │
└──────────────────────┴─────────────────────┘
```

- 右から左へドラッグすると章に入る。章の中もドラッグで並べ替えられる。
- 章の節には「断章ボックスに戻す」がある（左→右のドラッグでも戻せる）。
- 「普通の本文を追加」は右上。確定すると断章ボックスの一番上に入る。
